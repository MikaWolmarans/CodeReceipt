FAQ

What's in the full Owner's Manual?

15 sections: Quick Start, Architecture Overview, Key Systems, File Breakdown, Safe-To-Touch Map, Warning Lights, Risk Register, Running Costs, Environment Variables, AI Agent Handoff Prompts, Service Schedule, Troubleshooting, Known Unknowns, Glossary, and Next 5 Actions.

How much does it cost?

The scan is free. The full manual is pay-what-you-want — you name the price. Pay once, get the manual, done. No subscription, no auto-renewal, no "your trial is ending" emails. Skint students and funded founders pay on the same honour system. Push new code and want a fresh manual? Name a price for the new version.

Does it work on private repos?

Yes — via ZIP upload. Download your repo from GitHub/GitLab as a ZIP file and drop it into the uploader. No OAuth, no token, no access required. Your code is processed ephemerally and never stored.

How long does analysis take?

Free scans typically complete in 30–60 seconds. Paid full analysis runs in 1–3 minutes depending on repo size. You'll get an email when it's ready — no need to keep the tab open.

What happens after I pay?

Payment clears through an encrypted, PCI-compliant checkout — we never see or touch your card details. Then the real work starts: we run the full analysis pipeline, typeset your PDF, and email it to you with the file attached, usually within 2 minutes. A 30-day download link rides along in the same email.

How do I know my code is safe?

Because we built this the way we'd want our own repos handled. Your code is read in memory, analysed once, and dropped — never written to a database, never logged, never fed to a training set. No background access to your GitHub, no tokens sitting in someone's env file. We've shipped enough production code to be paranoid on your behalf.
