// The problem

The AI wrote it.
Now what?

Modern models can build you a working app in an afternoon. What they can't do is leave you understanding it. You end up with a repo full of code you didn't write, can't fully read, and are scared to change, because you don't know what's load-bearing and what's decoration.

CodeReceipt closes that gap. It's a skill your own coding agent runs against your repo. It scans the code, then hands you back the owner's manual the AI never wrote: what you actually shipped, how the pieces hold together, and exactly where the wires are live.

// What you get

Two files. Zero fog.

MANUAL.md for humans

A readable owner's manual for the person who owns the code. Written in plain English, deadpan, no filler.

  • What you built + a quick start
  • Architecture, in words you can follow
  • Key systems and what breaks if they fail
  • A safe-to-touch map (green → red)
  • Env vars, running costs, known risks
AGENTS.md for any AI tool

A universal agent-context file (written as both AGENTS.md and CLAUDE.md) so Claude Code, Cursor, Windsurf, Copilot and any other agent understand the codebase before they edit it.

  • Project overview + architecture
  • Key systems and their main files
  • Do-not-touch rules, spelled out
  • Env var names + purpose (never values)
  • Conventions the code already follows
// How it works

Scan. Read. Write.

01
Deterministic scan

A zero-dependency Python script walks your repo and pulls the facts: stack, file map, entry points, env-var names. No AI. No network. .env files excluded by design.

02
Your agent reads

Your own model reads the facts, opens the files that matter, and figures out what's really going on, marking anything it can't verify instead of guessing.

03
The manual lands

It writes MANUAL.md plus a universal AGENTS.md / CLAUDE.md straight into your repo. The model is yours, so there's nothing to pay and nothing to upload.

// Install

Two minutes.

Grab the skill and drop it into your project (or your user-level skills folder to use it everywhere).

1 · Clone the repo
# get the skill git clone https://github.com/MikaWolmarans/CodeReceipt.git
2 · Install the skill into your project
mkdir -p .claude/skills cp -r CodeReceipt/code-receipt-skill .claude/skills/code-receipt
3 · Ask your agent
› explain this codebase / document this repo / make me a CLAUDE.md

Prefer to just run the scanner? It's plain stdlib Python 3, no install:
python3 .claude/skills/code-receipt/scripts/scan.py . -o codereceipt-facts.json
